# Як викласти сайт у відкритий доступ (безкоштовно)

Проєкт — **Node.js + Express**. Потрібен хостинг, який тримає сервер постійно (не просто статичні HTML-сторінки).

## Рекомендація: Render.com (безкоштовно)

**Плюси:** проста реєстрація, безкоштовний URL типу `https://ваш-сайт.onrender.com`, підходить для навчального проєкту.  
**Мінуси:** після 15 хв без відвідувачів сервер «засинає» — перше відкриття може йти **30–60 секунд**; на безкоштовному тарифі файли на диску **можуть скинутися** при новому деплої — фото та правки в адмінці краще мати резервну копію папки `data/` і `public/uploads/`.

### Крок 1. GitHub

1. Зареєструйтесь на [github.com](https://github.com).
2. Створіть **новий репозиторій** (можна приватний).
3. Завантажте туди папку проєкту `BESHA` (через GitHub Desktop або `git`).

**Не комітьте паролі.** Файли `.env`, `data/admin.json` уже в `.gitignore`.  
`data/content.json` можна комітити — це контент сайту.

### Крок 2. Render

1. [render.com](https://render.com) → Sign Up (можна через GitHub).
2. **New +** → **Web Service**.
3. Підключіть репозиторій з проєктом.
4. Налаштування:
   - **Runtime:** Node
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
   - **Instance type:** Free
5. **Environment Variables** (обов’язково змініть пароль):
   - `ADMIN_USERNAME` = ваш логін
   - `ADMIN_PASSWORD` = надійний пароль
   - `SESSION_SECRET` = довгий випадковий рядок (Render може згенерувати)
6. **Create Web Service** — зачекайте деплой (5–10 хв).

7. Відкрийте URL з Render:
   - сайт: `https://....onrender.com`
   - адмінка: `https://....onrender.com/admin`

> Якщо після деплою не пускає в адмінку — видаліть на Render змінну не потрібна; на сервері створиться новий `admin.json` з паролем із `ADMIN_PASSWORD` лише якщо файлу немає. На безкоштовному Render диск тимчасовий — після redeploy може знову бути `admin`/`admin123`, якщо не задані env.

### Крок 3. Оновлення сайту

Змінили код локально → push на GitHub → Render сам перезбере проєкт.

Контент через адмінку на Render теж можна міняти, але **зробіть копію** `data/` перед кожним redeploy з GitHub.

## Інші безкоштовні варіанти

| Сервіс | Для кого |
|--------|----------|
| [Fly.io](https://fly.io) | Якщо готові трохи попрацювати з CLI; можна підключити том для файлів |
| [Oracle Cloud Free Tier](https://www.oracle.com/cloud/free/) | Повноцінна Linux-VM назавжди безкоштовно; складніше налаштувати |
| [Glitch](https://glitch.com) | Швидкий тест, але проєкт «засинає», диск нестабільний |

**Не підійдуть без переробки проєкту:** GitHub Pages, Netlify (лише статика) — у вас сервер і адмінка.
