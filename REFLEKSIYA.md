# Рефлексія

## Які Future Skills я використав/використала під час створення власного цифрового простору?

Під час розробки сайту «Мій професійний вебпростір» я застосував кілька ключових компетенцій сучасного цифрового світу.

**Цифрова грамотність** проявилася у виборі технологій (веб-сервер, безпечне збереження даних, завантаження зображень), налаштуванні структури проєкту та організації контенту так, щоб власник міг оновлювати сайт без програмування.

**Креативність** — у візуальному стилі: кольорова палітра, типографіка, картки навичок і портфоліо, анімації при прокрутці та зручна навігація, щоб ресурс виглядав як справжнє портфоліо, а не шаблонна робота.

**Критичне мислення** допомогло оцінити вимоги завдання: не імітувати «працюючу» форму без збереження даних, не вигадувати біографію власника, чесно позначити демонстраційні проєкти та передбачити захист адмін-панелі паролем.

**Комунікація** — у текстах українською: зрозумілі заголовки, підказки в панелі редагування та повідомлення про успішне збереження чи помилки, щоб людині без технічного досвіду було легко керувати сайтом.

**Вирішення проблем** — при проєктуванні API для контенту, валідації форми контактів, обробки помилок завантаження файлів і адаптивного меню для мобільних пристроїв.

**Самостійна робота з інформацією** — пошук і застосування підходів до CMS-подібного редагування, документації бібліотек (Express, сесії, multer) та перевірка сайту за формулою: зміст → структура → дизайн → навігація → мобільна версія → інтерактивність → актуальність.

У результаті цифровий простір поєднує презентацію особистості з практичним інструментом, який власник може підтримувати в актуальному стані самостійно.
