# Мій професійний вебпростір

Сучасний адаптивний сайт-портфоліо з **панеллю редагування** для власника (без зміни HTML/CSS/JS).

## Запуск на комп’ютері

1. Встановіть [Node.js](https://nodejs.org/) (версія 18 або новіша).
2. У папці проєкту виконайте:

**Windows (якщо PowerShell скаржиться на «выполнение сценариев»):**

- Подвійний клік по `start.bat` (сам поставить залежності), **або** у PowerShell / CMD:

```bat
npm.cmd install
npm.cmd start
```

**Або** у звичайному CMD (не PowerShell):

```bash
npm install
npm start
```

Якщо з’явиться **EADDRINUSE :3000** — порт уже зайнятий (часто сайт уже запущений). Спробуйте відкрити http://localhost:3000 або запустіть `stop.bat`, потім знову `start.bat`. Інший порт: `$env:PORT=3001; npm.cmd start` (PowerShell).

3. Відкрийте в браузері:
   - **Сайт:** http://localhost:3000
   - **Редагування (тільки для власника):** http://localhost:3000/admin

### Перший вхід

За замовчуванням (якщо не налаштовано `.env`):

- **Логін:** `admin`
- **Пароль:** `admin123`

**Обов’язково змініть пароль:** скопіюйте `.env.example` у файл `.env` і задайте `ADMIN_USERNAME` та `ADMIN_PASSWORD`, потім перезапустіть сервер. Якщо `data/admin.json` уже створено, видаліть його — обліковий запис створиться з новим паролем.

## Що може редагувати власник

Через панель `/admin` (після входу):

- ім’я, професія, тексти всіх розділів;
- біографія та фото;
- навички (додавання / видалення / опис);
- проєкти портфоліо (зображення, посилання, позначка «Приклад»);
- цілі та часова шкала;
- відео YouTube;
- контакти та посилання на соцмережі;
- перегляд повідомлень із форми зворотного зв’язку.

Зміни зберігаються на **сервері** у `data/content.json` і одразу видно всім відвідувачам після оновлення сторінки сайту.

## Форма зворотного зв’язку

Повідомлення **реально зберігаються** у `data/messages.json` і доступні в розділі «Повідомлення» адмін-панелі. Автоматичної відправки листа на пошту немає — для цього потрібно окремо підключити SMTP або сервіс (Formspree, SendGrid тощо).

## Публікація в інтернеті

Можна розмістити на будь-якому хостингу з підтримкою Node.js (Render, Railway, VPS тощо):

1. Завантажте проєкт.
2. Встановіть змінні середовища з `.env.example`.
3. Команда запуску: `npm start`.
4. Збережіть папки `data/` та `public/uploads/` (постійне сховище), щоб контент не губився при перезапуску.

## Структура

- `public/` — публічний сайт
- `server.js` — API, авторизація, завантаження файлів
- `data/content.json` — контент сайту
- `REFLEKSIYA.md` — рефлексія для навчального завдання
